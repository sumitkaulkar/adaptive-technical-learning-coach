# Course State Template

Use this exact format every time, so a course can be saved on one platform and resumed on another.

Save it as `course-state-<topic>.md` in the working folder when you can write files. In chat-only setups, print it as one clearly marked block for the learner to keep. See SKILL.md Section 9.

Keep it short. It is a pointer to where the learner is, not a copy of the lessons.

---
