# Changelog

## 1.3.0
- Every new course opens with a visible background check. The coach shows what it found about you (or says it found nothing) and asks you to rate the key prerequisites as know it well, partly, or new. Your ratings shape the plan.
- Past chats are only searched after you say yes.

## 1.2.1
- Clickable question panels are always backed up by the same questions in plain text, in case a panel fails to appear.

## 1.2.0
- The coach always asks how you want the lessons delivered: in chat, one document per module, or one combined document, and in which file type (Word, PDF, Markdown or the platform's own).
- Long courses get a one-line quality check at the end of each module from module 2 onward. The coach never forces a new chat; it offers a full hand-off package only after you say yes.

## 1.1.0
- Intake now scales to your deadline. Urgent courses start teaching by the second reply.
- New resume protocol and a fixed course state format, so a course can be saved on one platform and resumed on another.
- Quick one-off questions get a direct answer instead of a questionnaire.
- Works by capability, so the same skill runs in Claude and ChatGPT chat windows, workspace agents and coding agents.
- Core file cut from over 1,000 lines to under 400, with mode details moved into reference files.

## 1.0.0
- First version.
